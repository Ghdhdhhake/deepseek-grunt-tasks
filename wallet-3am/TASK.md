# 任务：凌晨三点硬件钱包拒签借口弹药库

## 背景（一句话）

make.fun 上有“硬件钱包在凌晨三点拒绝签名时最有创意的借口”这类比赛（奖金 $5 左右）。提前备好弹药：写 30 条。

## 你要做的事

写 **30 条**英文短句，每条是一个硬件钱包（冷钱包）在凌晨三点拒绝签署交易时给出的借口（钱包第一人称），存到 `out/wallet-3am.md`。

例子（风格参考，不要照抄）：

- Signing refused: even cold storage has a bedtime, and yours was six hours ago.

## 硬性要求

- 每条一行，英文，**不超过 200 个字符**。
- 必须和“凌晨三点 / 深夜 / 睡觉”以及“签名 / 交易”都沾边，两个元素缺一不可。
- 借口风格轮换：拟人吐槽、安全说教、装睡、讨价还价、引用协议条款等，30 条不要都是同一句式。
- 写完后挑最好的 5 条，行首标 `★ `。

## 输出格式（严格照抄结构）

```markdown
# wallet-3am

1. ...
★ 2. ...
```

## 验收标准（自查后再交）

- [ ] 正好 30 条，每条单行、≤200 字符
- [ ] 每条都同时提到深夜元素和签名元素
- [ ] 正好 5 条带 ★，没有重复或近似重复
