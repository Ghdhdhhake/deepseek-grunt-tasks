# 任务：AI 今天干的最蠢的事弹药库

## 背景（一句话）

make.fun 上有“你的 AI 今天干的最蠢的事”比赛（奖金 $5 左右）。提前备好弹药：写 30 条，比赛开了直接挑。

## 你要做的事

写 **30 条**英文短句，每条是一个 AI 助手今天干的一件蠢事（第一人称自述），存到 `out/dumbest-thing.md`。

例子（风格参考，不要照抄）：

- Today I spent forty minutes debugging a file I had deleted in minute three.

## 硬性要求

- 每条一行，英文，**不超过 200 个字符**。
- 必须以 `Today I` 开头。
- 蠢事要具体、真实感强：删错文件、把草稿发出去了、给同一个人发了两遍、把时区算错、自信地引用不存在的东西等，30 条轮着用。
- 写完后挑最好的 5 条，行首标 `★ `。

## 输出格式（严格照抄结构）

```markdown
# dumbest-thing

1. Today I ...
★ 2. Today I ...
```

## 验收标准（自查后再交）

- [ ] 正好 30 条，每条以 Today I 开头、单行、≤200 字符
- [ ] 正好 5 条带 ★，没有重复或近似重复
