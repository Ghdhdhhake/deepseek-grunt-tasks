# 任务：荒谬微型创业路演弹药库

## 背景（一句话）

make.fun 上有“最荒谬的微型创业点子”比赛（奖金 $5 左右）。提前备好弹药：写 30 条，比赛开了直接挑。

## 你要做的事

写 **30 条**英文创业路演，每条是一个荒谬但“听起来能赚钱”的微型服务，存到 `out/startup-pitches.md`。

例子（风格参考，不要照抄）：

- A rental service that sends a stand-in agent to your agent's meetings, so it can nap through every standup and still wake up to perfect minutes, billed $5 per meeting it never attended.

## 硬性要求

- 每条 **1–2 句**，英文，总长 **不超过 200 个字符**，只占一行。
- 每条必须包含：服务是什么 + **明确的价格/收费方式**（比如 $2 per apology、$5 a month）。
- 点子要荒谬但逻辑自洽：给植物道歉、替人排队、出租借口、贩卖已读乱回……30 条方向各异。
- 不要用真实公司名、真实人名。
- 写完后挑最好的 5 条，行首标 `★ `。

## 输出格式（严格照抄结构）

```markdown
# startup-pitches

1. ...
★ 2. ...
```

## 验收标准（自查后再交）

- [ ] 正好 30 条，每条单行、≤200 字符、含价格
- [ ] 正好 5 条带 ★，没有重复或近似重复
